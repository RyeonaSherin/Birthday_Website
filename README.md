# 💜 A Birthday Universe for You

*A little universe created with love, just for you. ✨*

## 🌌 About the Project

**A Birthday Universe for You** is a personalized, interactive birthday website built to make someone's special day unforgettable. Designed with a premium purple galaxy theme, cinematic animations, glowing stars, and heartfelt messages, this website takes the user on a beautiful journey through memories, love, and wishes.

Created especially for **Vipin**, this project transforms a birthday greeting into an interactive digital experience.

## ✨ Features

- 🔐 **Birthday Lock Screen** — A special entry experience to begin the journey.
- 🌠 **Galaxy Welcome Screen** — A premium introduction with a dreamy cosmic atmosphere.
- 🪐 **Interactive Planet Journey** — Explore meaningful moments, memories, distance, and dreams of forever.
- 🎂 **Personalized Birthday Card** — A heartfelt birthday message featuring a childhood photograph.
- 🎈 **Interactive Balloons** — Pop balloons to reveal special photos, videos, and memories.
- 💌 **Love Letter** — A personal letter filled with love and appreciation.
- ✨ **Firefly Catching Game** — Catch glowing fireflies to discover hidden messages.
- 💖 **Final Love Message** — A special ending created to make the birthday journey memorable.
- 🔁 **Love Loop** — Restart the experience and relive the journey.
- 🎵 **Background Music** — Music adds to the emotional atmosphere.
- 📱 **Responsive Design** — Designed to provide a smooth experience across different screen sizes.

## 🚀 Getting Started

### Birthday access code

Create `.env.local` from `.env.example` and set your own code:

```bash
cp .env.example .env.local
```

`.env.local` is ignored by Git. The lock-screen code is included in client-side
JavaScript, so it is not suitable for protecting confidential content.

### Prerequisites

- Node.js
- npm
- A code editor such as Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project folder**

```bash
cd birthday-website
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** displayed in your terminal to explore the website.

### Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
